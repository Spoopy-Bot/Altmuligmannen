# Altmuligmannen

Altmuligmannen er en klikkbar prototype av en app som hjelper folk å finne en altmuligmann eller håndverker til jobber hjemme. Vi har laget den til investorpresentasjonen og UX-dokumentasjonen i prosjektet. Det er bare en demo, så alt er oppdiktet og lagres kun i nettleseren din.

## Kjøre den

Du trenger Node 20 eller nyere. Så er det bare:

```bash
npm install
npm run dev
```

Åpne adressen som dukker opp i terminalen, som vanligvis er http://localhost:5173. Trenger du mer, finnes også `npm run build`, `npm run preview` og `npm run lint`.

## Prøve den

Velg **Jeg trenger hjelp** på forsiden, så er du Emma Haugen. Med **Demo**-knappen oppe til høyre kan du bytte rolle og person når som helst, og **Nullstill demo** tar deg tilbake til start.

Hva appen kan, og hvordan en jobb går fra start til slutt, står i [DOKUMENTASJON.md](DOKUMENTASJON.md). Koden ligger i `src/`.
